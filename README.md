🎀 Scientific Calculator

An interactive scientific calculator built with Python, Streamlit, HTML, CSS, and JavaScript.

Features
Basic arithmetic operations
Scientific functions: sin, cos, tan, log, ln, √, x², xʸ, n!
Inverse and hyperbolic trigonometric functions
DEG/RAD mode
π, e, Ans, %, and 1/x
Calculation history
Keyboard support
Responsive pink interface
Run
pip install streamlit
streamlit run app.py
Technologies

Python • Streamlit • HTML • CSS • JavaScript
